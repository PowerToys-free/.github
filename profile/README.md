## 🧠 Overview

Microsoft PowerToys is an open source set of system utilities for power users for use on Windows. These programs add or change features to maximize productivity or add more customization.

On a Windows machine it runs as a preset pack with its own workspace, settings folder and uninstall entry. Typical use is system utilities work on local files, so the application does not need a subscription or a cloud project to open and save documents.
